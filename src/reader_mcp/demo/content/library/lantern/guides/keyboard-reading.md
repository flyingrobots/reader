# A field guide to reading by keyboard

## Why the keyboard

A reader who never reaches for the mouse keeps their eyes on the page. Every key below works in the reading view; none of them needs a modifier.

## Moving through a document

| Key | Does |
| --- | --- |
| `j` / `k` | Scroll, or turn a spread in two-page mode |
| `gg` / `G` | Beginning / end |
| `]]` / `[[` | Next heading / start of this section |
| `/` | Find in this document |
| `n` / `N` | Next / previous match |

## Leaving marks

Select a passage, then choose **Highlight**, **Comment** or **Warn**. A warning is for a claim you doubt: it carries an explanation, so the next reader knows why.

## Finding your way back

`Space` then `e` opens the library. `Space` then `r` shows what is queued. `h` goes back to where you were.
