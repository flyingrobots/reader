## Request checks (every route)

- **Bind:** `WebServer` refuses any address but `127.0.0.1`/`localhost`. Port default 8766 (`reader web --port`, 0 = any free).
- **Identity (`web_access.WebAccess.identify`), before admission:** a request without proxy headers must have Host
  `127.0.0.1:<port>` or `localhost:<port>` and, if it sends Origin, the same origin; any forwarding/Tailscale header makes it
  *proxied*, which needs `trusted_proxy: tailscale`, a configured host matching X-Forwarded-Host, an allowed
  Tailscale-User-Login, no Funnel header and an allowed Origin. Refusal: 403 JSON `{error}` under `/api/`, else a 403 HTML page.
  Config: `<vault>/.reader/web-config.json` (≤ 64 KiB, no symlink) with `READER_WEB_*` overrides, re-read on change.
- **Writes (every POST):** header `X-Reader-Token` equal to the per-process token from `GET /api/library`, and
  `Content-Type: application/json`, else 403. Body must be a JSON object of 1 byte up to: `1024 ** 2 if parsed.path == '/api/prose' else 3 * 1024 ** 2 if parsed.path == '/api/art' else 128 * 1024`.
- **Admission:** expensive pool 8 slots (refuse 429 at once), read pool 32 slots (wait 5.0 s, then 429), SSE 4 streams (429), ungated: /, /api/health and /assets/, /fonts/.
- **Response headers:** every JSON/file response sets `X-Content-Type-Options: nosniff`, `Cache-Control: no-store`,
  `Referrer-Policy: no-referrer` and a CSP; raw vault files (`/api/file`, `/api/art/still`) get `sandbox` CSP, ranges
  (`Range: bytes=a-b`, 206/416) and `text/plain` unless the suffix is pdf/png/jpg/jpeg/webp/gif/svg.
- **Error mapping** (the `except` chain, in order):

| Exception | Status |
| - | - |
| `(BrokenPipeError, ConnectionResetError)` | none (connection dropped) |
| `MissingDocument` | 404 |
| `PermissionError` | 403 |
| `ProseUnavailable` | 409 |
| `(RunConflict, ChatOwned, ArtOwned, JobsOwned)` | 409 |
| `JobConflict` | 409 |
| `WritingConflict` | 409 |
| `BlockingIOError` | 429 |
| `SpeechUnavailable` | 503 |
| `TimeoutError` | 504 |
| `ArtMissing` | 404 |
| `(ValueError, TypeError, KeyError, OSError, sqlite3.Error)` | 400 |

Error bodies are `{"error": message}`; `shown()` rewrites absolute paths to `<vault>/…` or `~/…` (#105).
