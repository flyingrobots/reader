# Reading runner: narrow reads and validated completion

Removed the blanket filesystem read grant. The permission profile now permits Codex’s minimal platform paths, the selected source file, the Python runtime and the exact resolved Codex executable; notes are the only writable subtree. The native preflight additionally requires an unrelated-file read to fail. Resolving executable symlinks was necessary for the narrow profile; no home-directory grant or unrestricted fallback was added.

Added a structured final report and independent controller validation: exact source path/hash, integer line bounds, complete status, nonempty summary/coverage/opinion and a string-list uncertainty field. Missing, symlinked, oversized, malformed, mismatched or incomplete reports fail even after a zero child exit. Successful validation writes a completion artifact binding the report hash and selection. This is assertion/identity validation, not certification of semantic comprehension.

Eleven focused standard-library tests pass. Actual sandbox checks accept selected-source reads and notes writes, and refuse vault/outside writes, unrelated reads, symlink writes, protected-file hardlinks and networking. A real one-shot Codex run against a temporary synthetic three-line source completed successfully, reported the expected signal word and scene detail, and produced an identity/range-matched JSON report and controller completion artifact. The fixture used a separate temporary vault; no user library material was read by that model run.

Run `python3 -m unittest discover -s tests -p test_read_session.py` for component checks. To reproduce a full synthetic run, create an otherwise empty temporary vault with `library/fixture.md` and `inbox/`, set `READER_ROOT` to it, and run the installed helper with `library/fixture.md --notes NEW_EXTERNAL_DIRECTORY --seconds 120`. Check `report.json`, `completion.json` and source hashes. Normal account authentication is required; managed restrictions or unsupported CLI versions fail closed. No new background service, global configuration, remote push or merge.
